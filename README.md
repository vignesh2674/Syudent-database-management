# Student Database Management System (SLL)

A modular C-based Student Database Management System built using Single Linked Lists (SLL) for efficient record keeping and memory management.

## Features
- Add, delete, sort, and modify student records dynamically.
- Persistent data handling using file storage (student.dat).
- Modular C architecture (stu_main.c, separate functional modules, and custom header files).

## Compilation & Execution
Compile and run the project using the included Makefile:

# To compile the program
make

# To run the executable
./student

# To clean up compiled binaries and object files
make clear
